Introducción

¿Qué es Skäply?

Vamos a hacer una breve introducción sobre cuál es la funcionalidad de Skäply para entenderlo mejor.

Skäply es una aplicación web interactiva 3D para el montaje de muebles. Es decir, es una aplicación web donde los usuarios podrán ver el montaje de muebles de algunas marcas en 3D. En ella tendremos el montaje paso a paso, una simulación donde se va montando el mueble solo y el resultado del mueble montado donde se puede interactuar con él y sus piezas.

Como hemos mencionado, los usuarios finales serán los que utilicen esta herramienta para montar sus muebles y nuestro clientes serán las empresas que se unan a nuestra plataforma para tener el montaje de sus muebles.

Es una herramienta muy útil para aquellos que no se aclaran con los manuales en papel que ofrecen las empresas de muebles ya que pueden causar confusión. Con Skäply buscamos eliminar esos problemas y hacer más ameno el montaje de los muebles.

El objetivo de este objeto de aprendizaje es formar a los usuarios en el uso de una aplicación web 3D para el montaje de muebles, mostrando sus funcionalidades principales, el manejo del visor 3D y los distintos modos de montaje disponibles.
