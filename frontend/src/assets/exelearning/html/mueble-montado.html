Mueble montado

Resultado

En la opción de mueble dentro del visor 3D podemos ver el resultado del mueble montado. 

El usuario podrá interactuar con el mueble, ya sea rotarlo o ampliarlo. Tiene por defecto una rotación automática para ir viendo el mueble por delante y por detrás. 

A parte, también se podrá ver el mueble en realidad aumentada. El usuario tendrá una opción mediante un botón para poder abrir la cámara y el usuario situar el mueble en la zona deseada.
